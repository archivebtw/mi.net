## О проекте

**mi.net** — минималистичная социальная сеть, созданная как простое и спокойное пространство для общения в интернете.

Основная идея проекта — убрать визуальный шум, навязчивые рекомендации и перегруженный интерфейс, оставив только самое важное: людей, публикации, сообщества и общение.

В mi.net пользователи могут публиковать короткие посты, подписываться друг на друга, обсуждать темы, вступать в сообщества, сохранять интересные публикации и общаться в личных сообщениях.

Интерфейс построен вокруг чёрно-белой эстетики, строгой типографики и минимального количества декоративных элементов.

### Основные принципы

* минималистичный интерфейс
* быстрый и понятный UX
* фокус на контенте и общении
* персональные профили
* сообщества по интересам
* короткие публикации и обсуждения
* отсутствие лишних визуальных элементов
* адаптивность для desktop, tablet и mobile
